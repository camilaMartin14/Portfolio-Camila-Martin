# Portfolio — Camila Martín

🚀 [Ver portfolio online](https://portfolio-camila-martin.vercel.app/)

Desarrolladora Full Stack especializada en el ecosistema .NET. Me enfoco en construir soluciones escalables, desde APIs REST robustas hasta interfaces de usuario eficientes, aplicando buenas prácticas de arquitectura y diseño de software.

## 💻 Stack Tecnológico

- **Backend:** .NET 8, C#, ASP.NET Web API, Entity Framework Core.
- **Base de Datos:** SQL Server, T-SQL.
- **Frontend:** HTML5, CSS3, Vanilla JS.
- **Herramientas y Otros:** Git, Postman, Swagger, JWT, MinIO, Clean Architecture.

## ✨ Proyectos Destacados

### 📌 Tu Crédito — Sistema de Gestión de Préstamos
API Backend robusta diseñada para instituciones financieras. Automatiza el ciclo de vida de los préstamos con validaciones complejas y seguridad avanzada.
- **Tecnologías:** .NET 8 Web API, EF Core, SQL Server, JWT, MinIO.
- **Highlights:** Integración con BCRA, cálculo automático de intereses, manejo de archivos con MinIO.

🔗 [Repositorio](https://github.com/camilaMartin14/Tu-Credito) | 🌐 [Deploy](https://tu-credito.vercel.app/)

### 🎯 Logra — Daily Planner & Habit Tracker
Aplicación de productividad diseñada para maximizar el enfoque diario. Combina un backend optimizado con un frontend ligero y rápido.
- **Tecnologías:** .NET 8, SQL Server, Vanilla JS (SPA), Drag & Drop nativo.
- **Highlights:** Arquitectura limpia, solución al problema N+1, funcionamiento Offline-First.

🔗 [Repositorio](https://github.com/camilaMartin14/Logra--Daily-Planner) | 🌐 [Deploy](https://logra-psi.vercel.app/)
